**Combined free capacity:** ~125 req/min with one key each, **~375 req/min** with three keys per provider via [Multi-Key Rotation](/features/multi-key/). All $0.

## Adding API keys

Set the corresponding env var. Each accepts a single key OR a comma-separated list:

```bash
GROQ_API_KEY=gsk_...,gsk_another,gsk_third   # 3× the Groq capacity
GEMINI_API_KEY=AI...
MISTRAL_API_KEY=...
NVIDIA_NIM_API_KEY=nvapi-...
OLLAMA_BASE_URL=http://localhost:11434
```

Only the providers with valid keys are enabled at runtime. You don't need to provide all seven.
